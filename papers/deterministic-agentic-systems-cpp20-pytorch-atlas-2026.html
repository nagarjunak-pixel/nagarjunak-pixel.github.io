Abstract

Documents 16 clean-room C++20 and PyTorch 2.x reference implementations across 50 open-source repositories by Nagarjuna Reddy Kamireddy — spanning GRPO/DAPO RLVR post-training (veritas-rl), lossless speculative decoding & Top-K SAE steering (axiom-zero), 141.7x byte-DFA grammar decoding (syntara), SHA-256 Merkle trajectory bisection (tracegit), and C++20 HNSW/RaBitQ vector search (vecta).

Key Architectural Contributions

  • VeritasRL: Critic-free GRPO/DAPO RLVR post-training (8.0x Pass@1 lift), DoRA decomposition, and 2D Ring-Attention.
  • AxiomZero & TokenDiet: Lossless C++20 speculative decoding (4.00x fewer target passes), Top-K SAE steering, CDCL RUP checker, and 70.25% context compression.
  • Syntara & TraceGit: 141.7x byte-DFA constrained decoding (100% valid tool payloads) + Wagner-Fischer C++20 trajectory bisection.
  • WeaveGraph, Vecta, AetherCompiler & NexusVerity: Multi-agent AST merge verification, bit-exact vector search, SSA tensor compilation, and Double ML causal inference.
