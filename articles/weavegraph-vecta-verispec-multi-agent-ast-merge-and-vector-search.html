Parallel Multi-Agent AST Merge Verification, C++20 HNSW/RaBitQ Vector Search & Sub-Millisecond State-Machine Verification Gates: WeaveGraph, Vecta & verispec-sdd

Published November 18, 2026 · Codebases: weavegraph · vecta · verispec-sdd

1. WeaveGraph: Min-Cut Worktree Scheduling & 3-Way AST Semantic Merge Verification

Parallel coding agents running across isolated git worktree branches routinely pass line-based git merge cleanly while silently breaking cross-file arity, removed keyword parameters, or schema fields. WeaveGraph combines a native C++20 Compressed Sparse Row (CSR) graph engine (iterative Tarjan SCCs, reverse-dependency blast-radius BFS, and Fiduccia–Mattheyses / Kernighan–Lin min-cut partitioning) with a 3-way semantic AST merge verifier and stdio MCP server that catches silent contract breaks before merge.

2. Vecta: From-Scratch HNSW, IVF-PQ, 1-Bit RaBitQ & Hybrid BM25+RRF in Bit-Exact C++20

Production enterprise RAG requires explicit trade-offs across recall, RAM footprint, metadata filtering, and lexical exactness. Vecta implements all three primary Approximate Nearest Neighbor families plus hybrid retrieval from scratch with bit-exact float64 C++20 hot loops: (1) HNSW graph search with heuristic neighbor selection, filtered predicates, and tombstone deletes at 0.999 recall, (2) IVF-PQ residual product quantization with asymmetric distance tables, (3) 1-bit RaBitQ-style orthogonal rotations with hardware-popcount Hamming shortlists, and (4) Okapi BM25 + Reciprocal Rank Fusion (RRF).

3. VeriSpec-SDD: Executable SPEC.md State-Machine Verification & Property Synthesis

VeriSpec-SDD compiles declarative SPEC.md state machines into a C++20 CSR graph proving reachability, deadlock freedom, and Tarjan SCC livelock absence before agentic code generation, paired with automated Hypothesis and Vitest property-test synthesis.
