1. Executive Context: Why Raw Chatbot Wrappers Break on Enterprise ERPs

2. The 4-Layer SAP Model Context Protocol (MCP) Server Map

Connecting agents safely to Clean Core SAP S/4HANA and SAP BTP requires separating design-time metadata, runtime OData/CAP execution, integration governance, and read-only custom Z-code reconnaissance:

  1. Layer 1 — CAP Application MCP (@cap-js/mcp-server): Exposes CDS domain models, typed service definitions, and Clean Core BTP extension contracts directly to coding and orchestration agents.
  2. Layer 2 — ABAP ADT & Read-Only Z-Code Recon MCP: Inspects custom Z-tables, BAPIs, CDS views, and OBYC account-determination rules (such as distinguishing GBB/VBR internal consumption from GBB/VAX sales-order cost postings) in read-only mode before any plan is synthesized.
  3. Layer 3 — SAP Integration Suite MCP Gateway: Stateless Streamable HTTP transport enforcing SAP Cloud Identity Services (IAS) OAuth 2.1 principal propagation, rate-limiting, and audit logging across SAP and non-SAP endpoints.
  4. Layer 4 — Cloud Hyperscaler ERP Orchestration (AWS Bedrock / Private vLLM + MCP): Pairs cloud or sovereign GPU inference with deterministic policy sandboxes (aegis-runtime) and compensating saga rollbacks.

3. Table-Native Intelligence (SAP-RPT-1) vs. Text Serialization

Serializing wide SAP S/4HANA tables (ACDOCA, EKKO, EKPO, VBAK, MATDOC) into 70B text LLM prompts wastes 10× context tokens and loses relational foreign-key invariants. Pairing text-reasoning orchestrators with relational pretrained transformers (SAP-RPT-1 / in-database pushdown) and hybrid BM25 + dense + graph retrieval preserves foreign-key semantics while cutting latency and inference cost.

4. Pre-Execution Policy Gates & Independent Verification

In regulated finance and supply-chain operations, production confidence obeys a strict multiplicative invariant:

Confidence = Intent × Guardrails × Independent Verification × Evidence

If independent verification is zero, confidence is zero. Our open-source reference stack enforces this outside the generating LLM:

  • aegis-runtime: Custom Zero-Trust Policy DSL, compensating saga state machines for safe ERP rollback, and hash-chained Merkle/Ed25519 audit logs before any ACDOCA or procurement write-back.
  • prism-gate: OpenAI-compatible LLM FinOps gateway with TCP-Vegas adaptive concurrency, small-to-frontier model cascade routing, and PSI/JSD drift telemetry optimizing Cost-per-Completed-Workflow.
  • tracegit & syntara: SHA-256 Merkle trajectory bisection and C++20 byte-level DFA grammar-constrained decoding guaranteeing 100% schema-valid tool calls.
  • chronos-mesh: Pure-Python simplex + branch-and-bound MILP and Monte Carlo CVaR95 supply-chain optimization paired with ERP safety-stock constraints.
