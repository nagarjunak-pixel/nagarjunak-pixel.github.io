3aegis-runtimePython · FastAPI · Ed25519 Merkle LedgerPolicy and audit runtime for AI-agent tool execution featuring a custom capability DSL, segregation-of-duties enforcement, PII tokenization vault, compensating rollback sagas, and an Ed25519 hash-chained Merkle audit ledger.

7governed-member-services-agentPython · LangGraph · FastAPI · 40-Case Eval SuiteGoverned multi-tenant healthcare member-services workflow with deterministic tool authorization, grounded source citations, human escalation paths, and a 40-scenario CI regression harness.
8calibraPython · C++20 · mypy --strictStatistical LLM evaluation library providing paired bootstrap and exact McNemar tests, Bradley-Terry arena leaderboards with confidence intervals, 2PL IRT anchor scoring, temperature scaling, and C++20 MinHash-LSH contamination checks (99.6% test coverage).
9verispec-sddPython 3.13 · C++20 · FastAPI · MCP · React 18Executable SPEC.md compiler with a C++20 CSR reachability, co-reachability, deadlock, and Tarjan SCC livelock prover plus zero-eval() AST guards and Hypothesis/Vitest property-test synthesis (98.01% branch coverage).
10skillbenchPython 3.13 · C++20 Aho-Corasick · FastAPI · MCPStatic information-flow taint analyzer, OOXML/ZIP/.pyc de-obfuscator, and C++20 Aho-Corasick multi-pattern scanner auditing agent SKILL.md bundles and .mcp.json configurations in CI (97.97% branch coverage).
11weavegraphPython 3.13 · C++20 CSR Graph · FastAPI · MCP · React 18Dependency-aware git worktree scheduler using C++20 Tarjan SCC condensation, min-cut multi-agent task partitioning, and 3-way AST semantic merge verification to prevent cross-branch signature and contract breaks.
